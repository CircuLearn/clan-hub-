# 🤝 Contributing to the Clan

Thank you for your interest in contributing! Here's how to get started:

---

## 🧭 Step-by-Step

1. **Fork the repo** you want to contribute to
2. **Create a branch** (`feature/your-topic`)
3. **Make your changes**
4. **Commit** and push
5. **Create a Pull Request (PR)** with a clear description

---

## 🔖 Good Practices

- Keep PRs small and focused
- Comment your code where necessary
- Be respectful and constructive during code reviews
- Open issues for discussions before starting large changes

---

## 🌟 First Contribution Ideas

- Add yourself to the `members` repo
- Improve documentation or fix typos
- Suggest ideas in the `ideas` repo
